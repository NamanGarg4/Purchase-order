ERPNext Backend Customization – Purchase Order Module

This repository contains code from a project where I worked on making backend customizations in ERPNext, specifically focusing on the Purchase Order module. The changes were aimed at improving functionality, automating workflows, and tailoring the system to specific business requirements.


Project Overview

ERPNext is an open-source ERP system that helps manage various business processes including accounting, inventory, sales, and purchase management. In this project, I focused on:

* Customizing the Purchase Order workflow
* Implementing backend logic to meet specific business needs
* Modifying and extending ERPNext's default behavior to make the system more efficient and aligned with operational requirements


Technologies Used

* ERPNext – open-source ERP platform
* Frappe Framework – web framework underlying ERPNext
* Python – backend logic and server-side scripting
* MariaDB / MySQL – database used by ERPNext


Getting Started

If you want to explore or extend these customizations:

1. Install ERPNext following the official guide
2. Clone this repository into your ERPNext app directory
3. Apply the changes or custom scripts to the Purchase Order module
4. Test the workflow in a development environment before deploying to production
